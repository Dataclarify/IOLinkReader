# DataClarify

DataClarify — Machine Downtime Tracker

Real-time downtime monitoring for factory floors. Connects directly to Keyence IO-Link Masters via Modbus TCP. No cloud, no subscription, no IT setup required.

Download
→ DataClarify-v1.1-setup.exe — Windows installer (~80 MB)

Quick start

Run the installer
Open %APPDATA%\DataClarify\config.txt and set your machine IP and port
Double-click DataClarify.exe — the dashboard opens automatically in your browser
Requirements

Windows 10/11 (64-bit)
Port 8501 available
Network access to your Keyence IO-Link Master on port 502
